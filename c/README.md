# OCC eLibrary - Admin Dashboard

A comprehensive library management system for educational institutions, featuring eBook management, physical book tracking, program-based organization, and administrative controls.

## 🛠️ Technology Stack

### Frontend

- **React 18** - UI framework with hooks and functional components
- **React Router v7** - Client-side routing and navigation
- **Tailwind CSS** - Utility-first styling and responsive design
- **Recharts** - Data visualization and analytics charts
- **Lucide React** - Modern icon system

### Key Libraries

- **pdfjs-dist** - PDF processing and cover image extraction
- **react-hot-toast** - Toast notifications
- **react-select** - Enhanced select inputs with search
- **react-colorful** - Color picker for program customization
- **axios** - HTTP client for API integration
